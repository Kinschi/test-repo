# Junk or No

A beginner-friendly Next.js app that uses TailwindCSS and JavaScript to help users decide whether a typed food item is usually considered junk food.

## Features

- Type a food item and get an instant result.
- Try example buttons such as Apple, Pizza, Soda, and Grilled chicken.
- Beginner-friendly nutrition hints and simple language.
- Built with the Next.js App Router, TailwindCSS, and JavaScript.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
```
